# Code of conduct

PhoenixCSS discussions should be useful and respectful. Describe behavior and evidence, not a person's ability or motives. Welcome questions from people with different levels of experience. Avoid harassment, personal attacks, discrimination, and publishing someone else's private information.

If a discussion becomes unproductive, maintainers may ask participants to pause, edit a comment, or move the topic to a focused issue. Repeated or serious violations may lead to a block from project spaces. Decisions will consider the context and the effect on other participants.

For a concern involving abuse or private information, use [GitHub's report abuse process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) rather than posting details in a public issue. For an ordinary project discussion that needs moderation, open an issue with only the information safe to make public. For a security vulnerability, use the [private vulnerability reporting channel](SECURITY.md). A response time is not guaranteed while the project has one maintainer.
