# PhoenixCSS 0.1.0

PhoenixCSS starts with readable semantic HTML and adds optional layout classes when a page needs them. This first release contains a core stylesheet, a full stylesheet, and Sass sources. The four CSS files and npm tarball attached to the release are produced from the tagged commit; `SHA256SUMS.txt` lists their hashes.

Use `phoenix.core.min.css` for native content and forms, or `phoenix.min.css` for the responsive grid, cards, buttons, navigation styling, and utilities. Interactive navigation and dialogs require native browser behavior or your own JavaScript; PhoenixCSS does not ship a JavaScript runtime.

See the [README](https://github.com/OthmaneBlial/phoenixcss/tree/v0.1.0#readme), [examples](https://github.com/OthmaneBlial/phoenixcss/tree/v0.1.0/examples), and [migration guide](https://github.com/OthmaneBlial/phoenixcss/blob/v0.1.0/docs/MIGRATION.md). The included slate palette is a light example; a complete dark theme is not included. Browser CI and CSS checks run on the tag before the release is published. Accessibility still requires testing in each consuming site.
