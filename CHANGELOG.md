# Changelog

## Unreleased — proposed 0.1.0

The first verified release is still pending. The current source contains:

- Separate core and full CSS builds, each expanded and minified, with checked size budgets.
- A mobile-first grid, semantic content styles, keyboard focus, documented color roles, and a light slate override.
- A staged documentation site and three runnable examples for content, forms, and a small landing page.
- Node contract tests, HTML lint, local package installation checks, and CI browser journeys.

The initial checkout had a `1.0.0` manifest but no verified public release. The current manifest uses `0.1.0` for the first planned release. Source-level changes made before it are recorded in [the migration guide](docs/MIGRATION.md). A tag, downloadable artifacts, npm publication, and compatibility promise must be verified separately.
